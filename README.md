# Kopian

## Description
Kopian is a coffee shop management system designed to streamline operations, manage inventory, and enhance customer experience. It provides features for order management, inventory tracking, and customer relationship management.

## Features
- Order Management: Create, update, and track customer orders.
- Inventory Management: Monitor stock levels, manage suppliers, and track inventory movements.
- Customer Management: Maintain customer profiles, track purchase history, and manage loyalty programs.
- Reporting: Generate sales reports, inventory reports, and customer insights.
- User Management: Role-based access control for staff and administrators.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/maro14/kopian.git
   cd kopian
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
